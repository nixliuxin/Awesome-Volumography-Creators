## How to Add a Creator (via Pull Request)

### 1. Fork & Clone

```bash
git clone https://github.com/YOUR_USERNAME/Awesome-Volumography-Creators.git
cd Awesome-Volumography-Creators
npm install
```

### 2. Create Your Assets Folder

Create a folder named with your **creator ID** (lowercase, hyphenated):

```
website/assets/creators/{your-id}/
├── profile.jpg         # Avatar (must be named "profile")
├── my-best-work.png    # Cover (any non-profile image in root → auto cover)
└── gallery/            # Portfolio images (auto-detected)
    ├── anything.jpg    # ✨ Any filename!
    ├── my-work.png     # ✨ All auto-detected!
    └── ...
```

**Naming Convention:**
- **profile.\*** → Fixed name for avatar
- **Any other image in root** → Automatically becomes the cover (no special name needed)
- **gallery/\*** → Any filename, **automatically detected!**

**Supported Formats:** `jpg`, `jpeg`, `png`, `webp`, `gif`

**Image Guidelines:**
- Avatar: ~400x400px, square
- Cover: ~1200x800px, 3:2 ratio
- Gallery: Reasonable file size (< 500KB each)

### 3. Add Entry to creators.json

Edit `website/data/creators.json`:

```json
{
  "id": "your-name",
  "name": "Your Name",
  "title": "Gaussian Splatting",
  "subtitle": "Optional secondary title",
  "location": "City / Country",
  "links": {
    "ct": "https://www.creative.tech/...",
    "website": "https://your-website.com",
    "twitter": "https://twitter.com/...",
    "instagram": "https://instagram.com/..."
  },
  "tags": ["4DGS", "VFX", "Spatial Computing"]
}
```

**That's it!** No need to list image paths — they're auto-detected by ID.

> 💡 **Note:** The assets manifest is auto-generated by GitHub Actions when you submit a PR. No manual steps needed!

### 4. Test Locally (Optional)

```bash
npm run dev
```

### 5. Submit Pull Request

```bash
git add .
git commit -m "feat: add [Your Name] to creators"
git push origin main
```

Then open a Pull Request on GitHub.

## Field Reference

| Field | Required | Description |
|-------|----------|-------------|
| `id` | ✅ | Unique ID, lowercase with hyphens (e.g., `john-doe`) |
| `name` | ✅ | Display name |
| `title` | ✅ | Primary title/specialty |
| `subtitle` | | Optional secondary description |
| `location` | | City / Country |
| `links` | | Object containing all links (see below) |
| `tags` | | Array of tags |

**Link Options:**
| Key | Description |
|-----|-------------|
| `ct` | Creative.Tech profile (primary link) |
| `website` | Personal website |
| `twitter` | Twitter/X |
| `instagram` | Instagram |
| `youtube` | YouTube |
| `github` | GitHub |
| `linkedin` | LinkedIn |
| `tiktok` | TikTok |
| `vimeo` | Vimeo |
| `behance` | Behance |
| `dribbble` | Dribbble |

## Example

**Folder structure:**
```
website/assets/creators/jane-doe/
├── profile.jpg
├── splat-portrait.png    ← auto cover (any non-profile image in root)
└── gallery/
    ├── neon-city.jpg
    ├── forest-scan.png
    └── abstract.webp
```

**JSON entry:**
```json
{
  "id": "jane-doe",
  "name": "Jane Doe",
  "title": "Gaussian Splatting",
  "subtitle": "XR Artist & Researcher",
  "location": "New York",
  "links": {
    "ct": "https://creative.tech/jane-doe",
    "website": "https://janedoe.com",
    "twitter": "https://twitter.com/janedoe"
  },
  "tags": ["4DGS", "Art", "XR"]
}
```

**Run manifest:** `npm run manifest`

## Opt-Out Policy

This is a **celebratory curation** of artists and researchers pushing the boundaries of volumetric media. We deeply respect everyone's preferences regarding their online presence.

**If you prefer not to be listed:**

1. **GitHub Issue** (Recommended)  
   [Open a removal request](https://github.com/nixliuxin/Awesome-Volumography-Creators/issues/new?title=Removal%20Request:%20[Your%20Name]&labels=removal) with the title "Removal Request: [Your Name]"

2. **Direct Contact**  
   Reach out via [Creative.Tech](https://creative.tech)

**We will remove your entry within 48 hours, no questions asked.**

> 💡 This list is non-commercial and purely for community knowledge-sharing. We add creators based on their publicly visible work in the volumetric/3D scanning space.
